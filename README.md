# Python Fundamentals

A small, dependency-free Python learning repository. The example script uses
DevOps-themed values to demonstrate core Python syntax and built-in data types.

## Requirements

- Python 3

No third-party packages are required.

## Run the example

From the repository root, run:

```bash
python3 DAY1/1.py
```

The script prints examples and results to the terminal.

## Topics covered

`DAY1/1.py` demonstrates:

- Variables, values, and checking types with `type()`
- Converting between strings, integers, and floats
- Arithmetic, comparison, and logical operators
- Membership and identity operators
- String indexing, slicing, formatting, and common string methods
- Lists, tuples, and sets, including common operations
- Dictionaries, safe value access, updating and removing entries
- Iterating over dictionary items and accessing nested dictionaries
